# Парсер каталога в таблицу Excel

**Задача.** Заказчику нужен каталог конкурента или поставщика в виде таблицы:
чтобы сортировать по цене, фильтровать по наличию, считать средний чек.
Руками это часы работы и опечатки.

**Что сделано.** Скрипт обходит каталог постранично и складывает результат
в готовый xlsx: шапка закреплена, автофильтр включён, цена лежит числом,
а не текстом — по ней сразу работают сортировка и формулы.

**Результат прогона:** 1000 товаров с 50 страниц за 104 секунды,
файл [`output/catalog.xlsx`](output/catalog.xlsx) (73 КБ).

| Название | Цена, £ | Рейтинг | В наличии | Ссылка |
|---|---|---|---|---|
| A Light in the Attic | 51.77 | 3 | да | ссылка на товар |
| Tipping the Velvet | 53.74 | 1 | да | ссылка на товар |
| Soumission | 50.10 | 1 | да | ссылка на товар |

## Как запустить

    python3 -m venv .venv && .venv/bin/pip install -r ../requirements.txt
    .venv/bin/python parse.py --pages 50

Параметры: `--pages` — сколько страниц забрать, `--delay` — пауза между
запросами (по умолчанию 0.4 с), `--out` — куда сохранить файл.

Тесты: `.venv/bin/python -m pytest` — разбор страницы проверяется на сохранённом
куске HTML, без обращения к сети.

## Решения, которые обычно всплывают на реальном заказе

- **Цена числом.** Самая частая претензия к чужим парсерам: цена приходит строкой
  «£51.77», и в Excel по ней нельзя ни отсортировать, ни посчитать сумму.
- **Пауза между запросами.** Скрипт не долбит чужой сервер: 0.4 секунды между
  страницами. Быстрее — риск блокировки и претензий владельца сайта.
- **Повтор при сбое.** Сетевая ошибка на 37-й странице из 50 не должна убивать
  час работы: три попытки с нарастающей паузой.
- **Разбор отделён от загрузки.** Поэтому логика покрыта тестами на сохранённом
  HTML и не требует интернета при проверке.

## Про сайт для демонстрации

Демо собрано на [books.toscrape.com](https://books.toscrape.com) — это учебная
песочница, созданная специально для тренировки парсинга, ограничений на сбор
данных у неё нет.

Под конкретный заказ меняются селекторы в `extract_page` и список колонок —
структура скрипта остаётся той же. Если у сайта есть защита от ботов,
авторизация или данные подгружаются скриптами, это обсуждается отдельно:
такие случаи требуют другого инструмента и другого срока.

Сделано как демонстрация подхода, реального клиента за этим кейсом нет.
