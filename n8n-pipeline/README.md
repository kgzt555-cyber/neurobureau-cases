# Контент-конвейер в n8n: список тем → готовые посты

**Задача.** Бизнесу нужно выпускать посты регулярно, а пишутся они «когда руки
дойдут». Хочется поставить это на конвейер: закинул список тем — получил папку
готовых черновиков.

**Что сделано.** Сценарий в n8n: вебхук принимает список тем, по каждой теме модель
пишет пост, второй ИИ-шаг проверяет текст, код собирает markdown и складывает файлы
в папку. Пять тем — восемь секунд, пять готовых постов.

**Результат:** [`workflow.json`](workflow.json) — экспорт сценария,
[`data/out/`](data/out/) — посты с прогона.

## Три рубежа против выдуманных цифр

Самая честная часть кейса. Первый же прогон показал: модель-генератор украшает
посты несуществующей статистикой — «по данным исследований, 60% клиентов…».
Для бизнес-текстов это мусор, который стыдно публиковать.

Запрет в промпте помог наполовину: модель то слушалась, то нет. Поэтому в конвейере
три рубежа:

1. **Генератор** — пишет пост, промпт запрещает статистику.
2. **Контролёр** — вторая модель проверяет текст и переписывает места с цифрами
   на бытовые примеры.
3. **Фильтр кодом** — детерминированная страховка: предложения с процентами
   и «исследования показывают» вырезаются программно. Это не ИИ, ему нельзя
   «не послушаться».

Итог измерим: в выходных файлах нет ни одного процента и ни одной ссылки
на несуществующие исследования — проверяется грепом, а не глазами.

## Как запустить у себя

    docker run -d --name n8n-demo -p 5678:5678 \
      -e AI_API_KEY=ключ -e AI_BASE_URL=https://api.proxyapi.ru/openai/v1 \
      -e AI_MODEL=gpt-4o-mini \
      -e N8N_SECURE_COOKIE=false \
      -e N8N_BLOCK_ENV_ACCESS_IN_NODE=false \
      -e N8N_RESTRICT_FILE_ACCESS_TO=/data \
      -v n8n_demo_data:/home/node/.n8n -v "$PWD/data":/data \
      n8nio/n8n:latest

Дальше в интерфейсе n8n (localhost:5678): создать аккаунт, импортировать
`workflow.json`, активировать. Запуск:

    curl -X POST http://localhost:5678/webhook/content-pipeline \
      -H "Content-Type: application/json" \
      -d '{"topics":["Тема первая","Тема вторая"]}'

Ключ модели живёт в переменных окружения контейнера и в экспорт сценария
не попадает — `workflow.json` можно показывать и передавать безопасно.

## Ограничения, о которых честно говорю заказчику

- Это черновики: тон и факты о конкретном бизнесе всё равно вычитывает человек.
- Конвейер расширяется под задачу: вместо папки — Google-таблица, вместо вебхука —
  расписание, дальше по цепочке — генерация видео к каждому посту.

Сделано как демонстрация подхода, реального клиента за этим кейсом нет.
